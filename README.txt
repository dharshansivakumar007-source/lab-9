Employee Information XML Project

Files:
- index.html: Web page, styling, and JavaScript
- employee.xml: Sample employee information

How to run:
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Right-click index.html and choose "Open with Live Server".
5. Click "Load Employee Data" to display the XML records in the table, or click
   "Choose File" to select a local XML, CSV, or TXT file.

CSV and TXT files should have one employee per row, with the fields ID, Name,
Department, Salary, and City. A header row is optional. Comma-, tab-, semicolon-,
and pipe-delimited files are supported. Selected files are read in your browser
and are not uploaded.

Note: Use Live Server (or another local web server). Browsers may block XMLHttpRequest
when index.html is opened directly using a file:// URL.
